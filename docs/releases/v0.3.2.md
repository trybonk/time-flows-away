# Time Flows Away v0.3.2

First native Windows pre-release: a portable clock wallpaper with settings and
tray controls, independent of Wallpaper Engine.

## Included

- Date, clock and five progress bars for year, month, day, hour and minute.
- English settings with live preview, saved styles, custom text/fonts, Windows
  color emoji, PNG/JPEG backgrounds and countdown/elapsed timers.
- Tray Settings, Pause/Resume and Quit; opt-in startup at Windows sign-in.
- OpenGL by default, 30 FPS smooth bars, optional 60 FPS or animation off.
- Antialiased text, shared glyph caches, asynchronous image loading and reduced
  repaint cadence when the desktop is covered, locked or paused.
- Primary display/DPI handling and renderer recovery after Explorer restarts.
- Performance and lifecycle logs, plus PowerShell CPU/RAM/GPU measurement helpers.

## Requirements and scope

Windows 11 x64, **24H2 or newer**, with an OpenGL-capable graphics driver.
The wallpaper runs on the **primary display**. Extract the ZIP to a permanent
folder and run `time-flows-away-native.exe`; administrator rights are unnecessary.
The EXE is unsigned and there is no installer or automatic updater.

OpenGL resolved the reported foreground flashes on the user's RTX 3060. DX12
remains an optional diagnostic renderer (`--wgpu`); broad hardware compatibility
is not established. The normal OpenGL context workaround is retained.
Large/progressive/interlaced images may use more memory than ordinary backgrounds;
there is no fixed 150 MiB memory guarantee. Multi-monitor wallpaper is deferred.

## Validation

The preceding Windows MSVC builds passed formatting, Clippy, native tests,
PowerShell 5.1/7 helper checks, release compilation and packaging. The user
reported that the latest downloaded build works correctly. This release workflow
repeats those automated checks from the tag. Detailed measurements and remaining
Windows acceptance scenarios are recorded in `docs/VALIDATION.md` and
`docs/OPTIMIZATION-CHECKLIST.md` inside the ZIP.

The ZIP has a separate SHA-256 checksum. `build-manifest.json` records the source
commit, tag, workflow run and executable SHA-256 for diagnostics.
